# Проверка React в 1С

Простой счётчик для проверки загрузки React-приложения из GitHub в справочник `РеактивныеПриложения`.

## Проверка сборки

```powershell
npm ci
npm run build
```

Итог — один файл `dist/index.html` со встроенным JavaScript без модульных скриптов. Текущий механизм 1С сохраняет в справочник только этот файл.

## Загрузка в 1С

1. Создайте элемент справочника `РеактивныеПриложения`: наименование — `React тест`, идентификатор — `ReactDemo`, Git — `https://github.com/ban2zai/react-sz-test.git`, ветка — `main`.
2. Оставьте `Обновлять автоматически` выключенным и сохраните элемент.
3. Нажмите `Загрузить из коммита`, выберите коммит этого репозитория и дождитесь сообщения об успешной загрузке.
4. Нажмите `Сбросить кэш приложений`, затем откройте внешнюю обработку `ПросмотрReactТеста.epf`. В ней должна появиться кнопка `Нажато: 0`; каждое нажатие увеличивает счётчик.

Для сборки на сервере 1С нужны Git, npm и Node.js.
